# Germany

Sources of the data in this folder. Credit them when passing the data on.

| File | Source |
| --- | --- |
| `public-holidays.yaml` | Holiday laws of the federal states, Unification Treaty |
| `regions.csv` | Federal Statistical Office of Germany (Destatis), municipality register as of 31 December 2025 and Census 2022; redistribution permitted with attribution |
| `region-profiles.csv` | Bavarian State Office for Statistics, municipalities with Assumption Day (Art. 1 BayFTG) |
| `school-holidays/` | Standing Conference of education ministers (KMK), holiday calendars per school year; each file links its source |

Not included yet: Corpus Christi in the municipalities of Saxony and Thuringia where it applies.
